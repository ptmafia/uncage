# @uncage/testkit

Test helpers for adapter authors and app tests: `createFakeAdapter({ script })` is a scriptable fake runtime (text, approvals, waits, crashes). The adapter contract suite checks that a `RuntimeAdapter` emits well-formed event sequences, resolves approvals and honors aborts.
