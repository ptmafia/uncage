# @uncage/protocol

Wire types for Uncage: Zod schemas and TypeScript types for sessions, runs, events (a discriminated union on `type`), approvals, settings, attachments, runtime capabilities, the `RuntimeAdapter` contract, and the error catalog (every error has a code, HTTP status, message and hint). Browser-safe, no side effects.

---

Part of **Uncage** — bring Claude Code (and Codex) into your own app with approvals, streaming and a ready-made UI. Start with [`@uncage/react-ui`](https://www.npmjs.com/package/@uncage/react-ui) for the 5-minute setup. MIT licensed.
