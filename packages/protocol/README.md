# @uncage/protocol

The wire protocol shared by every package: TypeScript types and Zod schemas for sessions, runs, approvals and events, the `RuntimeAdapter` interface that adapters implement, and the error catalog. Every `ErrorCode` has an HTTP status, a human message and a hint. Browser-safe, with no Node imports.
