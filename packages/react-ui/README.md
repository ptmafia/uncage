# @uncage/react-ui

The default chat UI: `<AgentChat>` (session sidebar, runtime selector, streaming markdown, tool steps, approval cards, Stop, run status) inside `<UncageProvider>`. Import `@uncage/react-ui/styles.css` once. Theme it with the `--uncage-*` CSS variables; every class uses the `uc-` prefix. `locale` is `'en'` (default) or `'zh-CN'`. Model output is rendered as inert markdown (no raw HTML).

API: [`src/index.ts`](./src/index.ts) (every export is documented with JSDoc) · Project overview: [README](../../README.md)
